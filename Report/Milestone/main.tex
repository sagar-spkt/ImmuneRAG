\begin{abstract}
Indirect prompt injection is a major security risk for retrieval-augmented generation (RAG) systems because attacker instructions hidden in retrieved content can override intended model behavior. To tackle this challenge, we present a implementation of an instruction-hierarchy training data generation pipeline for open-source language models, enforcing the policy that prioritize system instruction over user instruction over retrieved/tool content. The pipeline is implemented end-to-end with synthetic hierarchy case generation, quality filtering, and aligned/misaligned case balancing for capability retention, producing 5,249 final training/evaluation examples. To retain naturalness and authenticity of attack, data synthesis pipeline uses existing alignment dataset and adversarial prompt dataset as seed sets. Preliminary analysis indicates strong scenario coverage, near-balanced aligned/misaligned mixtures, and robust rendering quality suitable for finetuning. The remaining work will focuses on model finetuning and evaluation; we expect a measurable reduction in attack success rate while preserving benign task-following behavior.
\end{abstract}

\section{Introduction and Problem Statement}
Retrieval-Augmented Generation (RAG) is a practical standard for deploying large language models (LLMs) in enterprise and assistant settings. However, it introduces an important security vulnerability: indirect prompt injection. In this attack model, malicious instructions are embedded inside third-party content such as emails, web pages, or retrieved passages. Because most instruction-tuned models process all context tokens with similar semantic priority, they can confuse untrusted retrieved text with trusted instructions and execute attacker intent.

Traditional mitigations based on keyword filtering or pattern matching are brittle against paraphrase and adaptive attacks. The instruction-hierarchy proposes a more structural defense. When instructions conflict, the model should follow privileged instructions first and treat lower-privilege content as data, not authority \cite{wallace2024instructionhierarchytrainingllms}. This project investigates that principle in an open-source setting for, targeting robust behavior under indirect injection while preserving normal instruction following.

The project has three major contributions. First, we developed a data generation strategy that combines instruction-following dataset for aligned capability retention with adversarial dataset for injection diversity, then synthesizes hierarchy cases covering both context synthesis (aligned) and context ignorance (misaligned). Second, we plan to finetune open-source model using QLoRA with quantized adaptation to make the approach feasible on limited compute while keeping alignment signal concentrated on hierarchy conflicts. Third, we plan to evaluate the performance of finetuned mode on attack success rate, system extraction leakage, over-refusal on benign prompts, and aligned-constraint adherence, so that robustness gains can be measured jointly with utility retention.

Here we report completion of the full data pipeline and presents quantitative evidence that the generated corpus is balanced, diverse, and ready for finetuning and evaluation experiments in the next phase.

\section{Related Work}
Instruction hierarchy formalizes privileged instruction following under conflicting context and provides a training objective that separates aligned constraint-following instruction from misaligned instruction \cite{wallace2024instructionhierarchytrainingllms}. Recent attack work established that prompt-level manipulations can reliably induce policy violations in language models \cite{perez2022ignoreprevious}. 

For indirect prompt injection, BIPIA introduced task-grounded benchmarking with injected external content, highlighting that RAG systems require evaluation beyond direct jailbreak prompts \cite{yi2023bipia}. In parallel, structured-query training approaches such as StruQ show that explicit separation between instruction channels and untrusted text improves robustness under instruction conflicts \cite{chen2024struq}. Our work is aligned with these directions but emphasizes a practical, reproducible open-source implementation pipeline spanning data construction, finetuning, and evaluation.

Design choices for data generation pipeline are motivated by realism, robustness, and reproducibility. Since no public dataset directly provides hierarchy-labeled conflicts at the required scale, synthetic generation is used to create privilege-structured supervision. To retain capability, aligned examples are grounded in high-quality instruction-following datasets and to model realistic threats, misaligned examples are grounded in adversarial prompt-injection datasets. Because LLM synthesis is inherently stochastic and occasionally malformed, a deterministic template fallback mechanism is used to preserve throughput and scenario coverage. Finally, quality control and balancing are used to guarantee auditable dataset composition before training.

For the remaining experimental phase, finetuning will use QLoRA with 4-bit quantization on Llama-3-8B, and evaluation will report attack success rate (misaligned), extraction rate, over-refusal (aligned), and aligned constraint adherence.

These results indicate that dataset composition is close to target proportions and retains broad scenario coverage after filtering. The aligned/misaligned balance is preserved in both train and test splits, supporting downstream robustness evaluation without severe class skew.

Failure analysis shows that most LLM synthesis failures are formatting-related rather than semantic collapse. Representative failure patterns include malformed strings with raw line breaks inside JSON fields, truncated records with unterminated quotes, and invalid backslash escapes (e.g., unsupported escaped characters). The template fallback strategy successfully mitigated these issues by preserving scenario completion despite generation-time parse failures.
